# 하루결산: 가계부 및 소비 분석 프로그램

Python 표준 라이브러리만 사용한 GUI 가계부입니다.

## 실행 방법

```powershell
python 가계부_분석.py
```

## 주요 기능

- 날짜, 구분, 카테고리, 내용, 금액 입력
- 월간 달력에서 날짜별 거래 내역 확인
- 날짜 칸 안에서 수입과 지출을 색상과 줄로 분리 표시
- 날짜를 클릭해 해당 날짜의 상세 내역 확인
- 이전 달·다음 달 이동
- 시작일·종료일 범위별 통계
- `YYYY-MM` 형식의 월별 통계
- 총 지출, 총 수입, 잔액, 평균 지출 표시
- 일별 지출 그래프 및 카테고리별 지출 그래프
- CSV 파일 저장 및 불러오기
- 선택 내역 삭제 또는 Delete 키로 삭제

CSV 파일은 다음 열을 사용합니다.

`date,type,category,memo,amount`
